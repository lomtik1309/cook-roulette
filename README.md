# Что приготовим? — статический сайт

Готовый офлайн-сайт с домашней рулеткой рецептов (72 блюда: по 24 на завтрак, обед и ужин). Все стили и скрипты уже собраны в папке `assets/`, внешние CDN не используются.

## Как быстро выложить в интернет

### Вариант 1: Netlify Drop (за 30 секунд, без регистрации через Git)
1. Откройте [app.netlify.com/drop](https://app.netlify.com/drop) в браузере.
2. Перетащите всю папку `site` в окно браузера.
3. Через несколько секунд получите готовую ссылку вида `https://....netlify.app`.

### Вариант 2: GitHub Pages
1. Создайте репозиторий на GitHub (или используйте существующий).
2. Загрузите содержимое папки `site` (`index.html` и папку `assets/`) в корень ветки `main` (или в папку `/docs`).
3. Откройте **Settings → Pages** в репозитории.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**, укажите ветку `main` и папку `/ (root)` (или `/docs`).
5. Нажмите **Save** — через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Локальный запуск
Если хотите проверить сайт локально с веб-сервера:
```bash
npx serve .
```
(запускать внутри папки `site`).
